# .claude — 作業規律キット

「レビューを飛ばさない・作業ツリーを取り合わない」を**機械で**担保するための一式。
jsl-hub の `.claude/` から持ち込み、juice 向けに調整した。

- **hooks** — `impl-review` の実施を機械的に強制する Stop フックと、スカッシュマージを強制する PreToolUse フック(詳細: [hooks/README.md](hooks/README.md))
- **skills** — 設計・実装・レビューの進め方。ユーザーが `/名前` で呼ぶことも、条件が揃えば自発的に発動することもある
- **settings.json** — フックの登録(パスは `$CLAUDE_PROJECT_DIR` 相対)
- **state/** — セッション別の状態。機械生成で git 管理外
- **handoff/** — 子セッションへの指示書(`orchestrate` が書く)。git 管理外

依存: `bash`・`jq`(必須)、`git`(一部のフックのみ)、`gh`(`worktree` スキルの `list`・`cleanup`)。`jq` が無ければレビュー強制のフックは無音で素通しする。

プロジェクト固有の事情(テストコマンド・ブランチ規則・マージ規則)は、スキルではなく **`CLAUDE.md`** に書く。スキル側は「`CLAUDE.md` / ビルド設定から確定する」と書いてあるだけで、具体値を持たない。

## スキル一覧

| スキル | いつ | 何を |
| --- | --- | --- |
| `tdd` | 実装フェーズ | Red→Green→Refactor。RedとGreenを別サブエージェントに分け、テストが実装に引きずられるのを防ぐ |
| `test-writing` | テストを書く/レビューする | 1テスト1検証・AAA(空行区切り)・期待値の丸ごと明示・負例の検証・変異解析 |
| `impl-review` | コードをコミットした作業の締め | 敵対的サブエージェント2観点(小差分・テストのみ・スタイルのみは1体に縮退)→修正→同一エージェントによる解消検証。Stopフックが未実施を検知 |
| `doc-review` | 文書を更新した作業の締め | 変更ファイル+関連文書に限定した即時レビュー。自発的に回す(強制するフックは無い) |
| `orchestrate` | 実装を別セッションへ出すとき | 司令が設計判断とレビューを持ち、実装は子セッション+別作業ツリーへ。司令はプロダクトコードを書かない |
| `worktree` | 実装の着手時・マージ後 | 既定ブランチの最新から作業ツリーを切る。マージ後はマージ済みの確認を通してから、作業ツリーとローカル・リモートのブランチを消す(実体は `scripts/wt.sh`、テストは `hooks/tests/worktree-script.test.sh`) |
| `writing` | 文書を書く・改訂する | 日本語の書き方規約(節単位の結論先行・一文一義・ひらく表記)。`/writing <ファイル>` で診断モード |

### 役割分担(重なったときはこの表が正)

| 変更したもの | 使うスキル | 重さ |
| --- | --- | --- |
| コード | `impl-review` | 敵対的2観点+検証ラウンド |
| 文書(変更したファイルとその周辺だけ) | `doc-review` | 軽い。変更のたびに自発的に |

`impl-review` は文書を見ず、`doc-review` はコードを見ない。両方を変えた作業では両方を回す。

書く側は、実装は `tdd`(進め方)+ `test-writing`(書き方)、文書の日本語の書き方は `writing`、実装を別セッションへ出すなら `orchestrate`、作業ツリーの作成と後始末は `worktree`。

**スキルは単体で読まれる。** Claudeは `description` を見て1つだけ読み込むことがあるので、
どのスキルも「他のスキルが導入されていること」を前提にしない。他スキルは**次の行き先として名前で1回だけ**指し、
無ければ同じことを自前で回す、と書く。

## jsl-hub から持ち込まなかったもの

jsl-hub の文書体系(決定記録 ADR + EARS 形式の仕様)を前提にする次のものは、juice には該当する体系が無いため入れていない。

- スキル: `spec-write`・`spec-review`・`drift-check`
- フック: `drift-check-gate.sh`(`drift-check` 未実施の `gh pr merge` を人の判断へ返す)

juice の `docs/` は `.gitignore` 対象のローカルメモで、リポジトリに入る文書は `CLAUDE.md`・`README.md`・`CHANGELOG.md` に限られる。
これらの整合は `doc-review` が見る。
